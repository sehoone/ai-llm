---
description: 환경별 전체 스택 배포 후 로그인 스모크 테스트 (ADR-0009)
---

사용자에게 `local`, `dev`, `stg`, `prd` 중 대상을 확인하고, 해당 환경의 설정 및
`SMOKE_BASE_URL`, `SMOKE_USERNAME`, `SMOKE_PASSWORD`가 준비됐는지 확인한다.
레포 루트에서 `task deploy-test ENV=<환경>`을 실행한다.

스모크는 선택한 환경의 `/health`와 로그인 토큰을 검증한다. 401이면 해당 환경의
테스트 계정과 DB 상태를 확인한다. 스키마 오류는 마이그레이션 상태를 확인하며,
데이터 손실 위험이 있으므로 볼륨 삭제를 해결책으로 자동 실행하거나 권장하지 않는다.
그 외 오류는 `deploy/README.md`의 환경별 로그 확인 절차를 따른다.

주의: 배포는 대상 환경을 변경한다. 운영 환경은 실행 전 사용자 승인을 받는다.
비밀정보나 `docker compose config` 출력을 대화에 노출하지 않는다.
